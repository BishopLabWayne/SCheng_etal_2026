# SCheng_etal_2026
Code that accompanies the manuscript "Controlled component segregation in vapor-deposited organic semiconductor glass mixtures" by S. Cheng et. al.

Phase separation code was written by Dean DeLongchamp
Analytical simulation code was written by Camille Bishop with assistance from Dean DeLongchamp
NEXAFS analysis and CyRSoXS/NRSS simulation code was written by Camille Bishop using principles and protocols from the Polymer Processing Group at NIST.
